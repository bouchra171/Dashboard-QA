DASHBOARD QA - MODE D'EMPLOI SIMPLE
===================================

1. Faites clic droit sur le ZIP, puis "Extraire tout".

2. Ouvrez le dossier extrait "Dashboard-QA".

3. Double-cliquez sur "Lancer-Dashboard-QA.cmd".

4. Utilisez le dashboard pour lancer les tests et consulter les resultats.

5. En cas d'erreur, faites une capture d'ecran complete et envoyez-la a l'equipe QA.
