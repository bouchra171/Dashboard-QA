Dashboard QA React - Demarrage

1. Ouvrir le dossier extrait.
2. Double-cliquer sur :
   CMDQA.cmd

Important :
- ne pas ouvrir index.html directement, sinon le navigateur peut afficher une page vide
- le fichier .cmd lance un mini serveur local puis ouvre le dashboard dans le navigateur
- le lanceur utilise le runtime portable inclus dans le dossier share quand il est disponible

Le dashboard est une demo React statique avec des donnees mockees realistes.
Il peut etre partage en dossier zippe ou en piece jointe telechargeable.
